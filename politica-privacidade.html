Política de Privacidade

Última atualização: 7 de Agosto de 2026

1. Introdução

A Teca Capital EdTech valoriza a privacidade dos seus utilizadores. Esta Política de Privacidade explica como recolhemos, utilizamos, protegemos e partilhamos os seus dados pessoais.

Estamos comprometidos com a proteção dos seus dados em conformidade com as legislações aplicáveis:

  • Angola: Lei de Proteção de Dados Pessoais (Lei n.º 22/11, de 17 de Junho)
  • Brasil: Lei Geral de Proteção de Dados (LGPD - Lei n.º 13.709/2018)
  • União Europeia: Regulamento Geral sobre a Proteção de Dados (RGPD/GDPR)

2. Dados Recolhidos

2.1. Dados fornecidos pelo utilizador

  • Identificação: Nome, email, telefone
  • Localização: País, Província/Estado
  • Dados de conta: Tipo de conta, plano contratado
  • Dados de pagamento: Comprovativos de pagamento

2.2. Dados gerados pela plataforma

  • Histórico de transações no simulador
  • Posições e carteiras de investimento
  • Progresso em provas de certificação
  • Interações com conteúdos (favoritos, likes)
  • Dados de acesso (IP, dispositivo, navegador)

3. Finalidades do Tratamento

Os seus dados são utilizados para:

  • Prestação do serviço: Acesso ao simulador, biblioteca e provas
  • Gestão da conta: Autenticação, recuperação de senha, suporte
  • Comunicação: Informações sobre o serviço, novidades, atualizações
  • Estatísticas: Análise de utilização, distribuição geográfica, melhorias do serviço
  • Segurança: Prevenção de fraudes e atividades maliciosas
  • Cumprimento legal: Obrigações fiscais e regulatórias

Os dados não serão utilizados para fins pessoais ou fora das finalidades previstas.

4. Base Legal para o Tratamento

  • Consentimento: O utilizador aceita a política ao criar conta
  • Execução de contrato: Prestação do serviço contratado
  • Interesse legítimo: Melhorar e personalizar a experiência do utilizador
  • Cumprimento legal: Obrigações legais aplicáveis

5. Partilha de Dados

A Teca Capital EdTech não partilha os dados dos utilizadores com terceiros, exceto nos seguintes casos:

  • Processadores de pagamento: Apenas para processamento de pagamentos
  • Obrigação legal: Quando exigido por lei ou autoridade competente
  • Consentimento explícito: Com a autorização prévia do utilizador

6. Direitos do Utilizador

O utilizador tem direito a:

  • Acesso: Saber quais dados são tratados
  • Retificação: Corrigir dados incorretos
  • Eliminação: Solicitar a remoção dos seus dados ("direito ao esquecimento")
  • Limitação: Restringir o tratamento de dados
  • Oposição: Opor-se ao tratamento de dados
  • Portabilidade: Receber os dados em formato estruturado

Para exercer estes direitos, contacte-nos através dos canais disponíveis.

7. Segurança dos Dados

Adotamos medidas técnicas e organizacionais para proteger os seus dados contra acesso não autorizado, perda, destruição ou alteração:

  • Criptografia: Dados em trânsito (HTTPS) e em repouso
  • Senhas: Armazenadas com hashing (bcrypt, salt 12)
  • Controlo de acesso: Apenas pessoal autorizado
  • Auditoria: Registo de todas as ações administrativas

8. Retenção de Dados

Os dados são mantidos enquanto a conta estiver ativa ou durante o período necessário para cumprir obrigações legais. Após o encerramento da conta, os dados serão eliminados ou anonimizados.

9. Cookies

Utilizamos cookies para melhorar a experiência do utilizador. O utilizador pode gerir as preferências de cookies no seu navegador.
